# Configuration

Hanya schema, loader, dan contoh konfigurasi yang boleh masuk Git. Nilai production disimpan di luar document root melalui hPanel atau file privat yang tidak terlacak.

Salin `.env.example` menjadi konfigurasi privat di server sesuai mekanisme yang tersedia. Jangan memasukkan password database, SMTP, Turnstile secret, Google secret, atau Midtrans Server Key ke repository.
